# Changelog

## 0.3.0 - 2026-09-26

First public GitHub package based on the v3 dashboard.

- Live crop, pivot and ARC geometry tuning on the cached frame.
- ARC and Hough needle detection, with automatic fallback.
- Multi-point angle-to-temperature calibration and final offset.
- ESP32-CAM acquisition through Home Assistant only.
- Flash warm-up, discarded priming frame, luminance-aware retries and delayed flash-off.
- Runtime acquisition controls and local history.
- Sanitized public ESPHome and Docker configuration examples.
